# Aviation ML Serving

<!-- [Codex · 2026-11-13] Initial project directory. -->

<!-- [Codex · 2026-11-13] Project brief. -->

Design an API for serving a versioned taxi-in time model. Start with a
synthetic request and response contract, then verify model versioning and
prediction reproducibility. Any future use of real inputs or model artifacts
depends on approval to use them. Taxi-in proxy labels and verified airport
observations have distinct meanings.
