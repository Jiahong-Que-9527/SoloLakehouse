# European Energy Pipeline

<!-- [Codex · 2026-11-13] Initial project directory. -->

<!-- [Codex · 2026-11-13] Project brief. -->

Ingest and validate a small slice of public electricity-market data. Start with
one German metric and a fixed date range. A later GCP milestone can run
ingestion in a Cloud Run Job, retain source data in Cloud Storage, and publish
a queryable table in BigQuery.
