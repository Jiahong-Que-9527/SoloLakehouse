## Pending work and restore boundaries

The [retained-work ledger](../../design/v3/retained-work.md) accounts for every unchecked item from the old TASKS snapshot. Only current TASKS sets priority; a historical unchecked line is not a new authorization.

The pre-v3 tag preserves the older main baseline; a separate complete Git bundle was verified before this rewrite at a1bef2e. Public source snapshots are not a backup of runtime data, ignored secrets or volumes. Independent recovery material remains private.
