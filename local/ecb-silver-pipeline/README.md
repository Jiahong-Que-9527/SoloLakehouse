# ECB Silver Pipeline

<!-- [Codex · 2026-11-13] Initial project directory. -->

<!-- [Codex · 2026-11-13] Project brief. -->

Create a standalone local reference for converting fixed ECB policy-rate inputs
to Silver rows. The first milestone records the input window and expected
output, including duplicate dates, missing rates, and basis-point changes. Use
the previous SoloLakehouse implementation as a comparison baseline.
