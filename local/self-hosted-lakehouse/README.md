# Self-hosted Lakehouse

<!-- [Codex · 2026-11-13] Initial project directory. -->

<!-- [Codex · 2026-11-13] Project brief. -->

Reproduce a small data flow in an isolated local environment using Compose,
Dagster, Iceberg, and Trino. The first milestone is a fixture run with a
verifiable query result. K3s, Flux, and recovery exercises are later
milestones.
