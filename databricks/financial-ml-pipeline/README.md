# Financial ML Pipeline

<!-- [Codex · 2026-11-13] Initial project directory. -->

<!-- [Codex · 2026-11-13] Project brief. -->

Build a batch ML exercise using versioned European financial time series. The
first milestone defines a feature set, a time-ordered split, and a simple
baseline. Later milestones can track experiment artifacts in MLflow and run the
workflow as a Databricks job.
