# First-boot contract

**Status: design only; hardware not provisioned.**

Define guest identity, trusted SSH user/key input, network/time prerequisites, guest integration and the handoff to configuration management.

No real user keys, cloud-init payload or network allocation is committed. First boot must be distinguishable from ongoing K3s management.

See the [authoritative design](../../docs/design/v3/architecture.md) and [construction-plan index](../../docs/design/v3/README.md).
